# AskBase

Natural Language Data Analytics Platform

## Overview

AskBase enables data analysts to query databases using natural language, generate reports, and build interactive dashboards.

## Quick Start

\`\`\`bash
# Install dependencies
docker-compose up

# Frontend
cd frontend && npm install && npm run dev

# Backend
cd ai-backend && pip install -r requirements.txt && uvicorn main:app --reload
\`\`\`

## Modules

- **Module 1 – Frontend**: React + TypeScript SPA
- **Module 2 – AI Backend**: FastAPI + Python AI engine
- **Module 3 – Data & Output**: Database, reports, PDF/PPT, exports
